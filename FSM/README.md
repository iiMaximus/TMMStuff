# FSM

Cleaned exam notes for Fundamentals of Structural Mechanics.

## Files

- `fsm-cheat-sheet-clean.md` - organized version of the photographed cheat sheet.
- `fsm-one-page-cheat-sheet.md` - compressed exam-day checklist.
- `tutorial-gap-audit.md` - formulas and methods found in the tutorial PDFs that were missing or underdeveloped in the photographed sheet.
- `printable-cheat-sheet.html` - print-ready HTML version for the exam.

## How To Use

Use the clean sheet as a workflow reference, not just a formula dump:

1. Pick the structure type.
2. Solve reactions first.
3. Choose the right internal-force method.
4. Use the correct stress or stability check.
5. Watch the traps listed at the end of each section.
